# Microsoft Azure Government — Account Executive Discovery Questions

## Scenario C: Hybrid GPU and Kubernetes workloads for DataWalk and Hyperscience

**Status:** Discovery and negotiation only. No pricing, funding, capacity, contractual protection or delivery commitment has been confirmed.

**Purpose:** Evaluate Microsoft's commercial proposal for selected Azure Government workloads while retaining remaining enterprise infrastructure on premises. This questionnaire complements the [technical discovery questionnaire](./azure-government-scenario-c-discovery.md) and [editable Draw.io architecture](./azure-government-scenario-c.drawio).

> Public-reference edition: internal budget figures, exact capacity requirements and project-specific deadlines are omitted. Discuss these through approved internal channels. All proposed concessions require procurement and legal review.

## 5. GPU capacity guarantees

A pricing reservation is not a capacity reservation. Ask whether capacity reservations are supported for the exact government region, GPU SKU and configuration. Request written commitments rather than assuming availability.

1. Can Microsoft contractually guarantee the required GPU capacity?
2. Can GPUs be reserved before production deployment?
3. Will reserved capacity incur charges before ATO approval?
4. Can Microsoft guarantee GPU availability for the expected five-year term?
5. What happens if the required GPU model becomes unavailable?
6. Can we upgrade to newer GPU generations without financial penalties?
7. Can replacement capacity be offered in another authorized government region?
8. What SLA or contractual remedies apply if promised capacity cannot be delivered?
9. Can production GPU capacity be reserved while keeping Dev/Test flexible?
10. Can Microsoft confirm the exact SKU, region, quantity and delivery date in writing?

## 6. ATO and financial risk protection

| Risk | Question |
|---|---|
| ATO delay | Can production commitments begin only after ATO approval? |
| ATO rejection | Can we terminate without penalties? |
| Implementation delay | Can credits and commitments be extended? |
| GPU shortage | Can financial commitments be suspended until capacity is available? |
| Service incompatibility | Can we cancel if either application cannot be supported? |
| Network delays | Can contractual milestones be adjusted? |
| Budget reduction | Can annual commitments be reduced? |
| Security limitations | Can we exit if mandatory government controls cannot be satisfied? |

Provider authorization is not workload ATO. Negotiate explicit conditions, remedies and obligations; do not treat these requests as existing Microsoft terms.

## 7. Predictable spending and cost management

1. Can Microsoft provide a five-year financial forecast with annual budget targets?
2. Can we establish contractual protections against unexpected price increases?
3. Can Microsoft provide monthly consumption reviews?
4. Can a dedicated FinOps specialist help optimize spending?
5. Can we receive notifications before exceeding the budget?
6. Can commitments be reduced if actual utilization is below projections?
7. Can Microsoft provide quarterly cost optimization assessments?
8. Can we access detailed cost and usage reports through APIs?
9. Can Azure Government export FOCUS-compatible billing reports?
10. How can we avoid paying for unused GPU capacity?

Budget alerts alone are not hard spending limits. Ask about actual resource enforcement, cost controls, overage rates and contractual protections.
